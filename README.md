Neon Sunset Cover Maker — turn your photo and a caption into GTA-poster-style cover art: multi-panel layouts, crop and position each photo, sunset or neon colour grades, bold condensed lettering, and one-click PNG export in 1080 × 1080, 1080 × 1350 and 1920 × 1080. A static web app that runs fully offline; photos are read on your machine and never uploaded.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, load a photo (or try a sample), pick a layout and grade, edit the caption, and hit Export PNG.
